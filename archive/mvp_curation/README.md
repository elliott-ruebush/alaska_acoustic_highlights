# MVP curation (archived)

Automated MVP highlights candidate generation from the full audio clips catalog. Superseded by the hand-curated 126-clip highlights set (`data/highlights_catalog.json` and related assets).

- `build_mvp_highlights_candidates.py` — score and cap the clean-candidate pool from `data/audio_clips_catalog.csv`
- `mvp_highlights_candidates.csv` — ranked output (2,384 candidates) used to inform hand curation
