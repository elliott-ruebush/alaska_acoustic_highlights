# Soundscapes of Alaska

Searchable library of NPS Alaska acoustic highlights — audio clips with spectrograms.

Audio from [NPS sound monitoring](https://www.nps.gov/subjects/sound/measure.htm).

**Site:** [freerange-elliott.com/alaska_acoustic_highlights](https://freerange-elliott.com/alaska_acoustic_highlights)  
**Repo:** [github.com/elliott-ruebush/alaska_acoustic_highlights](https://github.com/elliott-ruebush/alaska_acoustic_highlights)

```bash
cd site && npm install && npm run dev
```
